# Portfólio de Reinaldo Luiz da Silva

Site pessoal bilíngue que apresenta Reinaldo como profissional de Cloud/DevOps
para recrutadores e tech leads.

## Language

### Projetos

**Projeto**:
Trabalho próprio de Reinaldo, com repositório público, apresentado no site com
uma página de detalhe por idioma.
_Avoid_: case, trabalho, portfólio (para um item)

**Projeto em destaque**:
Projeto que representa o diferencial profissional de Reinaldo e recebe o maior
peso visual na home. Hoje é só o TicketOps.
_Avoid_: featured (na UI), principal

**Próximo projeto**:
Projeto em planejamento, mostrado com menos peso que um Projeto em destaque
para indicar direção sem prometer código que ainda não existe.
_Avoid_: em breve, roadmap

**Status**:
Estágio em que o Projeto está: Concluído, Em desenvolvimento ou Em
planejamento. Só se declara "Em desenvolvimento" quando há código no
repositório.
_Avoid_: fase, progresso

**Concluído**:
Status de um Projeto cujo escopo planejado foi entregue. Não significa
encerrado: um Projeto concluído ainda pode ter próximos passos.
_Avoid_: finalizado, encerrado, pronto

**Diagrama de arquitetura**:
Representação visual de um Projeto, mostrando os serviços e as nuvens
envolvidas. É a "imagem" do Projeto no site.
_Avoid_: thumbnail, screenshot, capa

### Credenciais

**Certificação**:
Credencial emitida por um provedor (Google Cloud, Oracle, Microsoft) e
verificável publicamente. Uma certificação ainda não obtida é "em andamento" e
não tem link de verificação.
_Avoid_: curso, badge, certificado (para cursos sem prova)
